# RustDesk

Your remote desktop software, built with Rust. Works out of the box, no configuration required. You have full control of your data, with no concerns about security.

## Features

- Cross-platform (Windows, macOS, Linux, iOS, Android, Web)
- Self-hosted or use public servers
- End-to-end encryption
- Low latency and high performance

## Quick Start

Download the latest release from [GitHub Releases](https://github.com/rustdesk/rustdesk/releases) and run it. For self-hosting, see [rustdesk-server](https://github.com/rustdesk/rustdesk-server).

## Build from Source

```bash
git clone https://github.com/rustdesk/rustdesk.git
cd rustdesk
cargo build --release
```
